# **App Name**: ConectarGC

## Core Features:

- New Member Onboarding: Automated WhatsApp follow-up tasks for new visitors, including initial contact, absence follow-up, and relationship building. Based on leader input about new members via the mobile app, the LLM tool will reason to send leaders personalized follow-up tasks, ensuring no one falls through the cracks.
- Care Radar: Automated alerts for absent members and tools for leaders to log member contact and prayer requests.
- Meeting Management: Digital check-in via WhatsApp, study library access, and task delegation features.
- Discipleship Tracking: Tools to track and manage the discipleship process.
- Leader Dashboard: Private micro-app for leaders to set goals, track personal growth, and access resources.
- Supervisor Web App: Web application for supervisors to monitor cell health, track leader activity, and manage users.
- Data Storage and Automation: Cloud Firestore database and Cloud Functions for Firebase to store data, process messages, and automate tasks.

## Style Guidelines:

- Primary color: Deep Purple (#6750A4) for a spiritual, calm, and reliable feel.
- Background color: Light gray (#F2F0F7) for a clean and modern base.
- Accent color: Violet (#9A89C6) to provide a visual call for leader engagement.
- Body and headline font: 'PT Sans' for a balance of modernism and approachability.
- Use clean and modern icons to represent different features and actions within the app. Icons should be easily understandable and consistent throughout the user interface.
- The leader interface will have a clear and intuitive layout optimized for quick task execution.
- Subtle animations will provide feedback on user actions.
